# RB Taxi Hodonín – Emerald full-site variant

Plnohodnotný statický vícestránkový web v barevném stylu **cream + emerald + mint + dark navy + jemné zlato**.

## Obsah
- 42 HTML stránek včetně 404
- responzivní desktop a mobilní verze
- služby, ceník, objednávka, aplikace, letiště, lokality, kariéra, FAQ a právní stránky
- SEO metadata, JSON-LD, sitemap.xml a robots.txt
- mobilní sticky CTA, kalkulačka, menu a cookie lišta
- konfigurace pro Vercel, Netlify a GitHub Pages

## Vercel
1. Nahraj rozbalený obsah do GitHub repozitáře.
2. Ve Vercelu zvol `Add New → Project` a importuj repozitář.
3. Framework preset: `Other`; Build command a Output directory nech prázdné.
4. Klikni `Deploy`.

## Důležitá poznámka
Tato varianta je plnohodnotný webový projekt, nikoli obrázek nebo maketa. Obsahově vychází z dříve připravené vícestránkové verze. Před ostrým nahrazením stávajícího webu je vhodné ještě provést přesnou obsahovou a funkční migraci proti aktuálnímu taxihodonin.com, zejména adresní kalkulačku, formuláře a řízení souhlasů cookies.
